# RYZE AI engineering environment

This directory contains selective, factual guidance for Claude Code and other
AI engineering tools. It is not loaded wholesale at session start.

- [Skills inventory](skills-inventory.md) — installed project skills, sources,
  licensing and when to use them.
- [Frontend revamp](frontend-revamp.md) — mobile-first redesign workflow,
  protected areas and visual constraints.
- [Database migration inventory](database-migration-inventory.md) — verified
  MariaDB/MySQL architecture and future PostgreSQL risks.
- [Claude Code workflow](claude-code-workflow.md) — selective context, skills,
  reviewer agents and verification commands.

The repository's product and engineering source of truth remains under `docs/`
and the mandatory instructions in `AGENTS.md`/`CLAUDE.md`.
